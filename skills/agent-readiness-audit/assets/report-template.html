Method

  1. Direct inspection of the working tree at {{REPO_PATH}} on {{DATE}} — directory structure, filename sweeps, line-count distribution, lint and CI configuration, boundary tests, and the instruction layer.
  2. Ten principles scored 0–10 against the agent-readiness rubric; the headline is their unweighted sum.
  3. Excluded from all counts: {{node_modules/, bin/, obj/, dist/, vendor/}}, and generated output.
  4. Not assessed: code correctness, test quality or coverage depth, runtime behavior, security, performance, or product fit. This audit measures structural legibility only — how cheaply an agent can find, predict, and verify. A codebase can score 100 here and still be wrong.
